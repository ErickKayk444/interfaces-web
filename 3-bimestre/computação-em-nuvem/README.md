# CloudTech — Computação em Nuvem

Site acadêmico desenvolvido em HTML5, CSS e Bootstrap 5.

## Páginas
- index.html
- sobre.html
- servicos.html
- vantagens.html
- contato.html

## Como executar
Abra o arquivo `index.html` no navegador.

O Bootstrap é carregado por CDN, portanto é necessário estar conectado à internet para carregar os componentes e estilos do Bootstrap.
